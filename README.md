One fortune cookie line for a crypto trader who has just been liquidated: the great wealth is still coming — it is just hiding in the couch cushions now, since the exchange took the rest.

> You will find great wealth in unexpected places, starting with the couch cushions, since the exchange took the rest.

## How it works

`main.py` (Python 3 standard library only) writes the fortune to `$MAKEFUN_OUTPUT_DIR/entry.txt`, checked first against the competition gate: 1 to 160 characters of UTF-8 text, a single line, at most 20 words.

```sh
python3 main.py
```
